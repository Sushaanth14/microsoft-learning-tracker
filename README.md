# Microsoft Learning Path Tracker

##  About the Project

Microsoft Learning Path Tracker is a web-based application designed to help students explore Microsoft learning courses in Cloud Computing and Artificial Intelligence.

It provides a structured learning roadmap and helps users understand course prerequisites and track their learning progress.

##  Features

- Separate learning paths for Cloud and AI.
- Displays Microsoft learning courses.
- Course prerequisite tracking.
- Course completion tracking.
- Google Gemini API integration for AI-generated course explanations.

##  Technologies Used

- **HTML** – Structure of the application.
- **CSS** – Styling and user interface.
- **JavaScript** – Application logic and interactivity.
- **Google Gemini API** – AI-generated course explanations.

##  How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the available learning paths.

Note: Gemini API functionality requires valid API configuration.
